# CRAFTD

Сайт студии ручной кастомизации одежды. PHP + MySQL. Запуск через XAMPP.

1. Скопируйте проект в `C:\xampp\htdocs\castomsite`
2. Запустите Apache и MySQL
3. В phpMyAdmin создайте базу `castomize` и импортируйте `database/schema.sql`
4. Скопируйте `config.local.php.example` → `config.local.php` (для XAMPP обычно ничего менять не нужно)
5. Откройте http://localhost/castomsite/
6. Админка: http://localhost/castomsite/admin/  
   Логин `admin`, пароль `admin123`.

Если папка называется иначе, подставьте её имя в адрес. Свои данные БД прописываются в `config.local.php` (образец: `config.local.php.example`).
